# Keyboard shortcuts

## Everywhere

| Keys | Action |
|---|---|
| Ctrl+K, Ctrl+F, Ctrl+Shift+P | Open the [command palette](User-Interface.md#command-palette) |
| Ctrl+1 | Tonight |
| Ctrl+2 | Sky |
| Ctrl+3 | Planner |
| Ctrl+4 | Observatory |
| Ctrl+5 | Deep sky |
| Ctrl+6 | Process |
| Ctrl+7 | Planetary |
| Ctrl+8 | Astrometry |
| Ctrl+9 | Photometry |
| Ctrl+Shift+N | Night vision (red) mode on or off |

## Command palette

| Keys | Action |
|---|---|
| ↑ / ↓ | Move through the results |
| Enter | Run the selected command or show the selected object |
| Esc | Close |

## Sky chart

Click the chart first so that it has the keyboard focus.

| Keys | Action |
|---|---|
| Arrow keys | Pan |
| + / − or Page Up / Page Down | Zoom in / out |
| N | Look north (planetarium mode) |
| E | Look east |
| S | Look south |
| W | Look west |
| Z | Look at the zenith |

| Mouse | Action |
|---|---|
| Drag | Pan |
| Wheel | Zoom |
| Click | Select an object |
| Double-click | Centre on that point |
| Right-click | Context menu |

## Image viewers

In Process, Deep sky, Planetary, Astrometry, Spectra, the Observatory and MPC astrometry.

| Keys | Action |
|---|---|
| + / − | Zoom in / out |
| 0 | Fit to window |
| 1 | Actual pixels (100%) |
| Arrow keys | Pan |

| Mouse | Action |
|---|---|
| Wheel | Zoom around the cursor |
| Drag | Pan |
| Drop a file | Open it (where supported) |

## Process

| Keys | Action |
|---|---|
| Ctrl+O | Open an image |
| Ctrl+S | Save as |
| Ctrl+Z | Undo |
| Ctrl+Y | Redo |

## Scripts

| Keys | Action |
|---|---|
| F5 | Run (or stop) the script |
| Ctrl+S | Save the script |
| Tab | Insert four spaces |

## Plots

| Mouse | Action |
|---|---|
| Drag | Zoom to a box, or select a range in light curves and spectra |
| Double-click | Reset zoom |
| Right-click | Reset zoom, copy image, save as PNG, export data as CSV |
